# GOLD AI TRADER PRO – OWM EDITION

منصة تحليل فني للذهب XAUUSD (فريم 5 و15 دقيقة) بواجهة عربية RTL. **إشارات وتحليل فقط، بدون تداول آلي أو ربط حسابات.**

## الملفات
`index.html` · `style.css` · `app.js` · `icon.svg` · `README.md`

## النشر المجاني على GitHub Pages (من الهاتف)
1. أنشئ مستودعاً جديداً على GitHub وارفع الملفات الخمسة (لا ترفع ملف ZIP نفسه).
2. Settings ← Pages ← Source: `main` / root ← Save.
3. افتح الرابط الذي يظهر (مثل `https://اسمك.github.io/اسم-المستودع/`).

## مصدر البيانات
- السعر: `https://biquote.io/api/XAUUSD` (يُستخدم `mid` و`dayDiffPercent`).
- الشموع: `https://biquote.io/api/XAUUSD/ohlc?interval=5m|15m&limit=180`.
- لم يمكن فحص شكل الاستجابة الحية أثناء الإنشاء، لذلك المحلل يقبل أسماء حقول شائعة (`t/time` و`o/open`… أو مصفوفات) ويُظهر خطأً واضحاً إذا لم يتعرف على الشكل. **لا تُعرض أي أسعار وهمية أبداً.**
- إن منع المصدر الطلبات من المتصفح (CORS) أو توقف، تظهر رسالة خطأ. بدائل مجانية: Twelve Data أو Alpha Vantage (تتطلب مفتاحاً؛ لا تضعه في كود المتصفح، استخدم وسيطاً مثل Cloudflare Worker).
- السعر قد يختلف عن سعر OW Markets (السبريد، المزود، التأخير).

## منطق الإشارة
EMA20/50 وRSI14 وATR14 ودعم/مقاومة (قمم وقيعان محلية) وزخم وحجم الشمعة. تُعطى BUY/SELL عند توافق 4 من 5 شروط وتعارض لا يزيد على 1، وإلا WAIT. تُمنع الإشارة عند: بيانات أقل من 60 شمعة، آخر شمعة أقدم من 3 فريمات، سوق مغلق (تقديري)، تضارب السعر مع الشموع، تشبع RSI، أو قرب دعم/مقاومة أقل من 1 ATR.
- Entry = السعر الحالي، SL = 1.5×ATR، TP1 = 1.5R، TP2 = 2.5R.
- «درجة التوافق» ليست احتمال نجاح.

## إدارة رأس المال
الافتراضي 30$ ومخاطرة 1–5%. حجم اللوت لا يُحسب إلا بعد إدخال حجم العقد من مواصفات وسيطك.
