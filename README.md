# GOLD SIGNAL STRATEGY PRO
موقع ثابت (HTML/CSS/JS بدون مكتبات خارجية) لإشارات الذهب. لا تداول آلي ولا ربط بحساب.

## التشغيل والنشر
- محلياً: افتح `index.html` عبر خادم بسيط (`python3 -m http.server`) أو انشر المجلد كما هو على Cloudflare Pages / GitHub Pages (لا يوجد build).
- الاختبارات: `node test.js`

## البيانات
نفس مصدر موقعك السابق: السعر `https://biquote.io/api/XAUUSD` (mid/bid/ask) والشموع `/ohlc?interval=1m|5m|15m|30m|1h&limit=500`، بدون مفتاح. لم أفحص الاستجابة الحية بنفسي، والمحلل يقبل أشكالاً شائعة ويُظهر خطأ واضحاً إن لم يتعرف عليها. إن لم يدعم المصدر 30m أو 1h مباشرة تُجمَّع من شموع 15m. فريم 1m غير مؤكد الدعم. عند الفشل لا تُعرض أسعار بديلة. السعر قد يختلف عن OW Markets.

## الاستراتيجية (أصلية، مستوحاة من الوصف العام لـ Edge Algo)
المعلومات العامة المتاحة عن Edge Algo (صفحة TradingView، سكربت بدعوة فقط): انقلاب اتجاه عبر قناة ATR، فلتر RSI وCMO، تأكيد بمحاور قمم/قيعان، SL ثم TP1/TP2/TP3 بنسب 1R/2R/3R. كوده الداخلي غير متاح، فهذا المؤشر **ليس نسخة منه ولا مطابقاً له**.
- BUY: انقلاب قناة ATR (SuperTrend 14×2) للأعلى + EMA20 صاعد + CMO>0 + RSI بين 40 و80 + شمعة صاعدة + دعم محور خلال 8 ATR + مجال حتى TP1 دون مقاومة. SELL عكسه (RSI بين 20 و60).
- فلتر التذبذب: أكثر من 3 انقلابات خلال 20 شمعة = لا إشارة. بيانات أقدم من 3 شموع = WAIT.
- الإشارة تُحسب على شمعة **مغلقة** فقط ولا تتغير بعد ذلك. الدخول = إغلاقها، SL = 1.5×ATR، الأهداف 1R/2R/3R، الصلاحية 5 شموع.
- النتيجة: ربح = TP1 قبل SL؛ خسارة = SL أولاً؛ الاثنان في شمعة واحدة = غير محسومة.
